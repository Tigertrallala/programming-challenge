Solution Data — Results

This section documents the canonical outputs produced by the challenge logic when run against the provided resource files.

Expected results (using shipped resources)

  • Weather challenge: Day with the smallest temperature spread — 14.
  • Countries challenge: Country with highest population density — Malta.

Console output example

Weather: day with smallest temperature spread = 14
Countries: country with highest population density = Malta

Programmatic result shape

The library/logic methods return simple types suitable for assertions or further processing:

  • WeatherLogic.findDayWithSmallestSpread → int (day number, or -1 when no valid rows)
  • CountryLogic.findCountryWithHighestDensity → String (country name, or "n/a" when no valid rows)

Notes

  • Invalid or malformed rows are skipped; logic functions return sentinel values for empty inputs so they are easy to test.
  • If you call the main application with custom resource paths, the same return types and console output format apply.
