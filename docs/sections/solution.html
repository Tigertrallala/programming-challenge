Solution Overview

  • Language & Tools: Java 11+, Maven (with wrapper), JUnit 5
  • Design: Modular, testable, extensible. IO, logic, and utilities are cleanly separated.
  • Data Readers: Pluggable TabularReader interface for CSV/JSON (easy to extend).
  • Business Logic: Stateless classes for each challenge, with robust error handling and logging.
  • Utilities: Console logger, progress bar, and EU number parsing.

All logic is covered by automated tests. Test and build scripts ensure repeatable results and easy review.
