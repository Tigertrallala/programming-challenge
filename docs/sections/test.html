Testing

Unit and integration tests (JUnit 5) in src/test/java:

  • CompactCsvJsonTest
    • testCompactWeatherCsvCases — validates CSV parsing for compact/edge cases (9 rows, missing fields, invalid numbers, unicode & special chars).
    • testCompactWeatherJsonCases — same validations for the JSON variant.
  • LogicIntegrationTest
    • testWeatherLogicWithOriginalResource — integration test using weather.csv, expects day 14.
    • testCountryLogicWithOriginalResource — integration test using countries.csv, expects Malta.
    • testWeatherLogicWithCompactCsv — weather logic on compact CSV, expects day 1.
    • testWeatherLogicWithCompactJson — weather logic on compact JSON, expects day 1.
    • testWeatherLogicWithEmptyRows — empty input returns -1 (no valid day).
    • testCountryLogicWithMinimalData — minimal valid data returns the only country ("Testland").
    • testCountryLogicWithEmptyRows — empty input returns n/a.

Run tests and generate HTML reports with the included helper:

.
runTests.cmd

This runs ./mvnw clean test site and executes save-report.ps1 to produce self-contained HTML files under reports/.
