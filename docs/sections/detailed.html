Detailed Solution & Code Snippets

Approach

The program is split into three concerns:

  • IO: Read CSV/JSON resources into List<Map<String,String>> via TabularReader.
  • Logic: Stateless classes implement the data computations (WeatherLogic, CountryLogic).
  • Util: Small helpers for parsing, logging and user feedback.

Key Code Snippets

Main orchestration — the application reads resources and invokes the logic classes:

public static void main(String... args) {
  String weatherResource = args.length > 0 ? args[0] : "de/bcxp/challenge/weather.csv";
  String countriesResource = args.length > 1 ? args[1] : "de/bcxp/challenge/countries.csv";

  List<Map<String,String>> weatherRows = TabularReader.read(weatherResource, ',', "Day", "MxT", "MnT");
  int dayWithSmallestTempSpread = WeatherLogic.findDayWithSmallestSpread(weatherRows);

  List<Map<String,String>> countryRows = TabularReader.read(countriesResource, null, "Name", "Population", "Area (km²)");
  String countryWithHighestPopulationDensity = CountryLogic.findCountryWithHighestDensity(countryRows);
}

Weather logic — computes smallest temperature spread, skipping invalid rows:

public static int findDayWithSmallestSpread(List<Map<String,String>> rows) {
  int bestDay = -1; int bestSpread = Integer.MAX_VALUE;
  for (Map<String,String> row : rows) {
    int spread = NumberParsing.parseInt(row.get("MxT")) - NumberParsing.parseInt(row.get("MnT"));
    if (spread < bestSpread) { bestSpread = spread; bestDay = NumberParsing.parseInt(row.get("Day")); }
  }
  return bestDay;
}

Country logic — computes population density and tracks the maximum:

public static String findCountryWithHighestDensity(List<Map<String,String>> rows) {
  String bestName = "n/a"; double bestDensity = -1.0;
  for (Map<String,String> row : rows) {
    double population = NumberParsing.parseNumber(row.get("Population"));
    double area = NumberParsing.parseNumber(row.get("Area (km²)"));
    if (area > 0.0) {
      double density = population / area;
      if (density > bestDensity) { bestDensity = density; bestName = row.get("Name"); }
    }
  }
  return bestName;
}
